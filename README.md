# 学草书

一个用来认草书的 Android 应用，学习节奏照搬背单词软件：一屏一个字，四选一，
连对三次算学会，之后按间隔复习。

单机应用，无账号、无广告，不联网也能用（一言会尝试联网，失败时用缓存）。

## 功能

**学习与复习**

- 一屏一张卡：给草书写法选对应的楷书，或者反过来
- 连对 3 次算学会；答错一次连击清零，重头再来
- 学会后按难度因子 `ef` 滚动复习间隔，间隔超过 100 天毕业
- 每个字的 `ef` 初值由字频决定：常用字 2.70，罕用字 2.00
- 答完自动展开解析：草书 / 楷书 / 繁体 / 繁草四个形一次看全

**穿插调度**

一轮里的字不是按顺序出，而是每次从「连击最少」的那批里随机挑一张，
并且同一个字至少隔两张卡，避免机械重复。

**字库页**

- 进度条 + 入口 + 四格统计 + 趋势图，一屏放下不用滑
- 全部 3755 个字：筛选（全部 / 未学习 / 复习中 / 复习完成 / 已标熟）、
  排序（字频 / 字库顺序 / 乱序）、右侧快速滚动条
- 单击切换草书·楷书显示，长按多选，可批量标熟、重学、收藏

**我的**

- 三套草书字体可选：行云草书、钟齐流江、毛泽东字体
- 三套常规字体可选：系统字体、霞鹜文楷、思源黑体
- 点击音效与震动的强度可调（0-100，0 即关闭）
- 进度导出 / 导入 / 清除

## 数据

| 数据 | 来源 |
|---|---|
| 字库 | GB2312 编码空间，6763 字 |
| 形近字 | Unicode Unihan `kRSUnicode`（部首）+ `kTotalStrokes`（笔画） |
| 繁简对照 | Unicode Unihan `kTraditionalVariant`，2329 字 |
| 字频 | Jun Da 现代汉语字频表（语料库统计） |
| 一言 | hitokoto.cn |

繁简对照记录三种草书字体各自的字形覆盖情况，显示时优先用当前选中的字体，
缺字形就退回行云，三者都没有才不显示「繁草」列。

## 字体授权

- **行云草书** —— 随附授权书，见原字体包
- **钟齐流江毛笔草体** —— 免费字体

## 构建

需要 JDK 21 与 Android SDK 35：

```bash
./gradlew assembleRelease
```

`release` 目前复用 debug 签名，仅供自用安装，不能上架应用商店。

Maven 依赖走阿里云镜像（`maven.aliyun.com`），因为部分网络环境访问 `dl.google.com` 会超时。

## 技术栈

Kotlin 2.0 + Jetpack Compose (Material 3)，单 Activity，无 ViewModel、无数据库。
状态集中在 `AppState`，进度存 JSON 文件，设置存 SharedPreferences。

- `AppState.kt` —— 队列构建、连击与 ef 计算、批量操作
- `data/Store.kt` —— CSV 资源与进度文件读写
- `ui/Study.kt` —— 答题页
- `ui/Book.kt` —— 字库与统计
- `ui/Settings.kt` —— 我的

进度每天自动备份一份 `progress.bak.json`，主文件丢失或写坏时自动回退。

- 连击制学习：连对 3 次学会，答错清零
- `ef` 难度因子驱动的间隔复习，间隔超过 100 天毕业

- 点击音效与震动强度可调
- 进度自动备份

### v1.1

- **断点续学**：学到一半退出，下次接着上次那一轮（字池、已完成数、每个字的连击都保留）
- **字库三档**：GB2312 一级 / 二级 / 一级+二级（6763 字），进度条上方显示当前字库名
- **学习计数**从 0 开始，不再一进来就是 1/20
- **穿插调度重做**：改成间隔排期 —— 答错插回 1~3 位、连对 1 次 3~6 位、连对 2 次 6~10 位，
  每个字并行推进，不再是「先把几个字刷毕业」
- **一言**：字号固定不再随字数缩小，按标点断句各自成列，一列排满才另起一列
- **新增「一言字号」**设置（28–80sp）
